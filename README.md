# Demo_Augmentation
The documentation is at [github.com/Hergoss/AUT_demonstrator](https://Hergoss.github.io/AUT_demonstrator/)

## Getting started
1) install skimage, cv2 in your environment
2) run example.py

## Current Augementations
- background
- rotation, translation
- other screws
- blur (not active)
- noise (not active)
